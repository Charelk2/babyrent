# Mosselbay Baby Gear

A static website prototype for a baby gear rental service.

## Pages

- **Home (`index.html`)**: Landing page with hero section, categories, and testimonials.
- **Catalog (`catalog.html`)**: Product browsing with filters.
- **Product Details (`product.html`)**: Detailed view of specific items.
- **Rental Process (`rental_process.html`)**: Step-by-step booking wizard.
- **Dashboard (`dashboard.html`)**: User account management and rental history.
- **Contact (`contact.html`)**: Contact form and "About Us" information.

## How to View the Website (GitHub Pages)

You can host this website directly on GitHub for free using GitHub Pages. This will give you a public URL to share and interact with the site without buying a domain.

1.  Go to the **Settings** tab of this repository on GitHub.
2.  In the left sidebar, click on **Pages**.
3.  Under **Build and deployment** > **Branch**:
    *   Select `main` (or the branch where this code resides, e.g., `jules/create-website`) from the dropdown menu.
    *   Ensure the folder is set to `/ (root)`.
4.  Click **Save**.

GitHub will take a minute or two to deploy your site. Once done, a link will appear at the top of the Pages settings page (e.g., `https://your-username.github.io/your-repo-name/`). Click that link to view the live website!
